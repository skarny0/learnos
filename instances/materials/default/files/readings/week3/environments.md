# Agent environments

## What an environment is
State, observations, actions, dynamics. The reward is a separate claim about what matters.

## Partial observability (POMDP)
When the agent cannot see the full state it must maintain a belief and sometimes act to gather information. Measurement can be an action with a cost.

## Attention as a hidden variable
Learners do not read everything shown to them. Attention gates learning and drains with fatigue.
